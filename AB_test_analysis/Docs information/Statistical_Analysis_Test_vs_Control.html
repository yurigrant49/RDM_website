📋 Project Overview

Statistical Analysis: Test vs Control is an interactive web application designed for comparing experimental (Test) groups against baseline (Control) groups using rigorous statistical methods. This tool enables data-driven decision making by providing comprehensive statistical analysis with intuitive visualizations.

🎯 Purpose

  • Compare performance metrics between Test and Control groups
  • Determine statistical significance of observed differences
  • Calculate effect sizes to understand practical impact
  • Support data-driven decision making for business experiments

🚀 Quick Start Guide

Step 1: Access the Application

  1. Open the application in your web browser
  2. You’ll see two file upload sections: Control Group and Test Group

Step 2: Prepare Your Data Files

Control Group CSV Requirements:

  • Must contain a column named “control”
  • File should contain baseline/current state data

Test Group CSV Requirements:

  • Must contain a column named “test”
  • File should contain experimental/new feature data

Step 3: Upload Your Files

Option A: Drag & Drop (Recommended)

  1. Drag your Control CSV file to the left upload area (blue border)
  2. Drag your Test CSV file to the right upload area (blue border)
  3. Wait for green confirmation messages

Option B: Click to Browse

  1. Click “Drag & drop Control CSV file here” and select your Control file
  2. Click “Drag & drop Test CSV file here” and select your Test file
  3. Wait for file processing to complete

Step 4: Analyze the Data

  1. Click the “Analyze Data” button (becomes enabled after both files upload successfully)
  2. The system will automatically process and display results

📊 Understanding the Results

1. Data Preview Section

  • First 10 records from each dataset
  • Quick verification that data loaded correctly
  • Sample values and formatting check

2. Sample Information

Control Group (Baseline):

  • Sample size (n)
  • Mean (average value)
  • Standard deviation (variability)
  • Variance

Test Group (Experiment):

  • Same metrics as Control group
  • Enables quick comparison of basic statistics

3. Histogram Visualizations

  • Distribution patterns for both groups
  • Frequency analysis — how values are distributed
  • Visual comparison of data spreads
  • Outlier detection through distribution shape

4. Statistical Test Results

Z-Test Results:

  • Z-Score: Measures how many standard deviations the Test mean is from Control mean
  • Critical Value: ±1.96 (for 95% confidence level)
  • P-value: Probability that observed difference occurred by chance
  • Conclusion: Clear “Reject” or “Do Not Reject” Null Hypothesis

Interpretation Guide:

Z-ScoreP-valueConclusionBusiness Meaning
> 1.96 or < −1.96< 0.05Reject NullStatistically significant difference
−1.96 to 1.96≥ 0.05Do Not RejectNo significant difference found

5. Effect Size Analysis (Cohen’s d)

Effect Size Interpretation:

Cohen’s dEffect SizePractical Meaning
0.0 – 0.2Very SmallNegligible difference
0.2 – 0.5SmallNoticeable but small effect
0.5 – 0.8MediumModerate practical effect
> 0.8LargeSubstantial practical effect

6. Statistical Power

  • Power (1−β): Probability of detecting a real effect
  • Type II Error (β): Probability of missing a real effect
  • Confidence Level: 95% (industry standard)
  • Type I Error (α): 5% (false positive rate)

🎨 Color Coding & Visual Indicators

Result Cards

  • Blue Border: Normal/neutral state
  • Red Background: Statistically significant result
  • Green Background: Not statistically significant

Conclusion Text

  • Red “Reject”: Strong evidence of difference
  • Green “Do Not Reject”: Insufficient evidence of difference

Effect Size Bar

  • Gray: Very Small (0.0–0.2)
  • Green: Small (0.2–0.5)
  • Yellow: Medium (0.5–0.8)
  • Red: Large (> 0.8)

💡 Best Practices for Analysts

Data Preparation

  1. Ensure data quality before uploading
  2. Remove outliers if they don’t represent typical behavior
  3. Check for missing values — the system filters them automatically
  4. Verify column names exactly match requirements

Interpretation

  1. Consider both statistical AND practical significance
  2. Large sample sizes can find tiny but unimportant differences
  3. Small effect sizes may still be business-critical
  4. Always check histograms for data distribution patterns

Reporting

  1. Include sample sizes in all reports
  2. Report both p-values and effect sizes
  3. Note confidence intervals for context
  4. Consider power analysis for experiment design

🛠️ Troubleshooting Common Issues

File Upload Problems

  • “CSV must contain ‘control’ column”: Check your column name spelling
  • “No valid numeric data found”: Ensure values are numbers, not text
  • File not loading: Verify it’s a proper CSV format

Analysis Issues

  • Unexpected results: Check histograms for data distribution
  • Extreme p-values: Verify data ranges and outliers
  • Low power: Consider increasing sample size for future tests

Technical Issues

  • Charts not displaying: Refresh the page and re-upload files
  • Slow performance: Large files (>10,000 rows) may take longer to process

🎯 Key Takeaways for Decision Makers

When to ACT on Results

  • ✅ Statistically Significant + Large Effect Size = Strong case for implementation
  • ✅ Statistically Significant + Medium Effect Size = Worth considering with other factors
  • ⚠️ Statistically Significant + Small Effect Size = Evaluate cost/benefit carefully
  • ❌ Not Statistically Significant = Insufficient evidence to proceed

Questions to Ask

  1. Is the difference statistically reliable? (p-value)
  2. How large is the practical impact? (effect size)
  3. Do we have enough data to be confident? (power)
  4. What do the distributions tell us? (histograms)
